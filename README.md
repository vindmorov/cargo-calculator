# Экономика рейса

Локальный интерактивный прототип калькулятора грузоперевозки с двумя режимами: «Интерфейс» и «AI-ассистент».

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

Готовые статические файлы находятся в `dist/`.

## Локальные ресурсы

- Шрифты TT Norms Tochka Extended хранятся в `public/fonts/`.
- Исходный код находится в `src/`.
- Согласованная спецификация и исходный промт находятся в `docs/`.
- В интерфейсе нет загрузки шрифтов, изображений или других ресурсов по удалённым URL.

Текущая финансовая модель демонстрационная. Перед production-использованием необходимо перенести и проверить точные формулы исходного калькулятора.
